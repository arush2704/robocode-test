# Directed Graph Cycle Detection Documentation

## Overview
This document describes the implementation and usage of the `hasCycleDirectedGraph` function in `Evaluation.java`, which detects cycles in a directed graph using Depth-First Search (DFS).

## Function Signature
```
public static boolean hasCycleDirectedGraph(List<List<Integer>> graph)
```
- **Input:**
  - `graph` (List<List<Integer>>): Adjacency list representation of the graph. `graph.get(i)` contains a list of nodes j such that there is an edge i→j.
- **Output:**
  - `boolean`: `true` if the graph contains a cycle, `false` otherwise.
- **Throws:**
  - `IllegalArgumentException` if the graph is null.

## Algorithm
- Uses DFS to traverse the graph.
- Maintains a `visited` array to track visited nodes and a `recStack` (recursion stack) to track the current path.
- If a node is revisited while still in the recursion stack, a cycle is detected.
- Handles disconnected graphs by checking all nodes.

## Example Usage
```
List<List<Integer>> graph = Arrays.asList(
    Arrays.asList(1),
    Arrays.asList(2),
    Arrays.asList(0)
);
boolean hasCycle = Evaluation.hasCycleDirectedGraph(graph); // true
```

## Complexity
- **Time Complexity:** O(V + E), where V is the number of vertices and E is the number of edges.
- **Space Complexity:** O(V) for the visited and recursion stack arrays.

## Edge Cases
- Empty graph: Returns false.
- Null graph: Throws `IllegalArgumentException`.
- Self-loops and disconnected components are handled correctly.
