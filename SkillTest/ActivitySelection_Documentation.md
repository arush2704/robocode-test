# Activity Selection Problem Documentation

## Overview
This document describes the implementation and usage of the `activitySelection` function in `Evaluation.java`, which solves the activity selection problem using a greedy algorithm with interval sorting.

## Function Signature
```
public static List<Integer> activitySelection(int[] start, int[] end)
```
- **Input:**
  - `start` (int[]): Array of activity start times.
  - `end` (int[]): Array of activity end times (must be same length as start).
- **Output:**
  - `List<Integer>`: List of selected activity indices (0-based, in order of selection).
- **Throws:**
  - `IllegalArgumentException` if input arrays are null, empty, or of different lengths.

## Algorithm
- Pairs each activity with its index, start, and end time.
- Sorts activities by end time (earliest finish first).
- Iterates through sorted activities, greedily selecting the next activity that starts after or at the end of the last selected activity.
- Returns the indices of the selected activities.

## Example Usage
```
int[] start = {1, 3, 0, 5, 8, 5};
int[] end =   {2, 4, 6, 7, 9, 9};
List<Integer> result = Evaluation.activitySelection(start, end);
// result is [0, 1, 3, 4]
```

## Complexity
- **Time Complexity:** O(n log n) due to sorting, where n is the number of activities.
- **Space Complexity:** O(n) for storing activity objects and the result list.

## Edge Cases
- Empty input: Throws `IllegalArgumentException`.
- Null input: Throws `IllegalArgumentException`.
- Mismatched input lengths: Throws `IllegalArgumentException`.
- All overlapping or all non-overlapping activities are handled correctly.
