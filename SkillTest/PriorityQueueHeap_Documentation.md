# PriorityQueueHeap Documentation

## Overview
This document describes the implementation and usage of the `PriorityQueueHeap<T>` class in `Evaluation.java`, which simulates a generic priority queue using a binary heap. It supports both min-heap and max-heap behavior via a comparator.

## Class Signature
```
public static class PriorityQueueHeap<T>
```
- **Constructor:**
  - `PriorityQueueHeap(Comparator<? super T> comparator)`: Creates a priority queue with the specified comparator (min-heap or max-heap).
- **Methods:**
  - `void add(T value)`: Adds an element to the queue.
  - `T poll()`: Removes and returns the highest priority element.
  - `T peek()`: Returns the highest priority element without removing it.
  - `int size()`: Returns the number of elements in the queue.
  - `boolean isEmpty()`: Returns true if the queue is empty.

## Algorithm
- Uses a binary heap (array-based) to maintain the heap property.
- Supports both min-heap and max-heap via the provided comparator.
- Maintains O(log n) time complexity for add and poll operations.

## Example Usage
```
PriorityQueueHeap<Integer> minHeap = new PriorityQueueHeap<>(Comparator.naturalOrder());
minHeap.add(3);
minHeap.add(1);
minHeap.add(2);
int min = minHeap.poll(); // min == 1

PriorityQueueHeap<Integer> maxHeap = new PriorityQueueHeap<>(Comparator.reverseOrder());
maxHeap.add(3);
maxHeap.add(1);
maxHeap.add(2);
int max = maxHeap.poll(); // max == 3
```

## Complexity
- **Time Complexity:** O(log n) for add and poll, O(1) for peek, size, and isEmpty.
- **Space Complexity:** O(n) for n elements in the queue.

## Edge Cases
- Polling or peeking from an empty queue throws `NoSuchElementException`.
- Passing a null comparator to the constructor throws `IllegalArgumentException`.
