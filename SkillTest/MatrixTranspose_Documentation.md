# Matrix Transpose Documentation

## Overview
This document describes the implementation and usage of the `transposeMatrix` function in `Evaluation.java`, which transposes a given matrix (converts rows to columns and vice versa).

## Function Signature
```
public static int[][] transposeMatrix(int[][] matrix)
```
- **Input:**
  - `matrix` (int[][]): The input matrix to transpose.
- **Output:**
  - `int[][]`: The transposed matrix.
- **Throws:**
  - `IllegalArgumentException` if the input is null, empty, or has inconsistent row lengths.

## Algorithm
- Validates that the input matrix is not null or empty.
- Checks that all rows have the same number of columns (rectangular matrix).
- Creates a new matrix with swapped dimensions.
- Copies elements from the original matrix to the transposed matrix by swapping indices.

## Example Usage
```
int[][] input = {
    {1, 2, 3},
    {4, 5, 6}
};
int[][] result = Evaluation.transposeMatrix(input);
// result is:
// {
//   {1, 4},
//   {2, 5},
//   {3, 6}
// }
```

## Complexity
- **Time Complexity:** O(m * n), where m is the number of rows and n is the number of columns.
- **Space Complexity:** O(m * n) for the transposed matrix.

## Edge Cases
- Empty matrix: Throws `IllegalArgumentException`.
- Null matrix: Throws `IllegalArgumentException`.
- Jagged matrix (rows of different lengths): Throws `IllegalArgumentException`.
- Single row or single column matrices are handled correctly.
