# Largest Prime Factor Documentation

## Overview
This document describes the implementation and usage of the `largestPrimeFactor` function in `Evaluation.java`, which finds the largest prime factor of a given number.

## Function Signature
```
public static long largestPrimeFactor(long n)
```
- **Input:**
  - `n` (long): The number to factorize (must be >= 2).
- **Output:**
  - `long`: The largest prime factor of `n`.
- **Throws:**
  - `IllegalArgumentException` if `n` is less than 2.

## Algorithm
- Removes all factors of 2 from `n`.
- Iterates through odd numbers from 3 upwards, removing all factors of each.
- If the remaining `n` is greater than 2, it is prime and is the largest factor.
- Returns the largest factor found.

## Example Usage
```
long result = Evaluation.largestPrimeFactor(13195); // result is 29
long result2 = Evaluation.largestPrimeFactor(600851475143L); // result2 is 6857
```

## Complexity
- **Time Complexity:** O(sqrt(n)) in the worst case.
- **Space Complexity:** O(1), uses constant extra space.

## Edge Cases
- Input less than 2: Throws `IllegalArgumentException`.
- Prime input: Returns the number itself.
- Power of two: Returns 2.
