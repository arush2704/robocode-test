# TTLCache Documentation

## Overview
This document describes the implementation and usage of the `TTLCache<K, V>` class in `Evaluation.java`, which simulates a generic cache with TTL (time-to-live) expiration for each entry. The cache is thread-safe for basic operations and supports custom TTL per entry.

## Class Signature
```
public static class TTLCache<K, V>
```
- **Constructor:**
  - `TTLCache(long defaultTtlMillis)`: Creates a cache with the specified default TTL (in milliseconds).
- **Methods:**
  - `void put(K key, V value)`: Puts a value in the cache with the default TTL.
  - `void put(K key, V value, long ttlMillis)`: Puts a value in the cache with a custom TTL.
  - `V get(K key)`: Gets a value from the cache, or null if not present or expired.
  - `void remove(K key)`: Removes a value from the cache.
  - `int size()`: Returns the number of unexpired entries in the cache.
  - `void cleanup()`: Removes all expired entries from the cache.

## Algorithm
- Uses a `ConcurrentHashMap` to store cache entries, each with a value and expiration timestamp.
- On `get`, checks if the entry is expired and removes it if so.
- `cleanup` can be called to remove all expired entries.
- Thread-safe for basic operations.

## Example Usage
```
TTLCache<String, Integer> cache = new TTLCache<>(1000); // 1 second TTL
cache.put("a", 1);
Integer value = cache.get("a"); // returns 1 if not expired
```

## Complexity
- **Time Complexity:** O(1) for put, get, and remove. O(n) for cleanup.
- **Space Complexity:** O(n) for n entries in the cache.

## Edge Cases
- Expired entries are removed on access or cleanup.
- TTL must be positive; otherwise, throws `IllegalArgumentException`.
- Overwriting a key resets its value and TTL.
