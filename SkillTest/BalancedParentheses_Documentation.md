# Balanced Parentheses Generation Documentation

## Overview
This document describes the implementation and usage of the `generateBalancedParentheses` function in `Evaluation.java`, which generates all combinations of well-formed (balanced) parentheses for a given number of pairs.

## Function Signature
```
public static List<String> generateBalancedParentheses(int n)
```
- **Input:**
  - `n` (int): Number of pairs of parentheses.
- **Output:**
  - `List<String>`: All valid combinations of balanced parentheses.
- **Throws:**
  - `IllegalArgumentException` if `n` is negative.

## Algorithm
The function uses a backtracking approach:
- It recursively builds strings by adding '(' or ')' at each step.
- It ensures that at no point do closing parentheses exceed opening ones, and that the total number of each does not exceed `n`.
- When the string reaches length `2*n`, it is added to the result list.

## Example Usage
```
List<String> result = Evaluation.generateBalancedParentheses(3);
System.out.println(result);
// Output: [((())), (()()), (())(), ()(()), ()()()]
```

## Complexity
- **Time Complexity:** O(4^n / sqrt(n)), which is the nth Catalan number.
- **Space Complexity:** O(4^n / sqrt(n)) for storing all valid combinations, plus O(n) for the recursion stack.

## Edge Cases
- `n = 0`: Returns a list with an empty string.
- `n < 0`: Throws `IllegalArgumentException`.
