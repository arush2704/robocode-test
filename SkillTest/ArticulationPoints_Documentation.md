# Articulation Points (Cut Vertices) Documentation

## Overview
This document describes the implementation and usage of the `findArticulationPoints` function in `Evaluation.java`, which finds all articulation points (cut vertices) in an undirected graph using Tarjan's algorithm (DFS-based).

## Function Signature
```
public static Set<Integer> findArticulationPoints(List<List<Integer>> graph)
```
- **Input:**
  - `graph` (List<List<Integer>>): Adjacency list of the undirected graph. `graph.get(i)` contains the neighbors of node `i`.
- **Output:**
  - `Set<Integer>`: Set of articulation point indices.
- **Throws:**
  - `IllegalArgumentException` if the graph is null.

## Algorithm
- Uses DFS to assign discovery and low-link values to each node.
- A node is an articulation point if:
  - It is the root of DFS and has more than one child.
  - It is not the root and there exists a child such that no node in the child's subtree has a back edge to an ancestor of the node.
- Handles disconnected graphs by running DFS from all unvisited nodes.

## Example Usage
```
List<List<Integer>> graph = Arrays.asList(
    Arrays.asList(1),
    Arrays.asList(0,2,3),
    Arrays.asList(1),
    Arrays.asList(1)
);
Set<Integer> result = Evaluation.findArticulationPoints(graph); // result is [1]
```

## Complexity
- **Time Complexity:** O(V + E), where V is the number of vertices and E is the number of edges.
- **Space Complexity:** O(V) for visited, discovery, low-link, parent arrays, and result set.

## Edge Cases
- Single node: No articulation points.
- Disconnected graphs: Finds articulation points in all components.
- Null graph: Throws `IllegalArgumentException`.
