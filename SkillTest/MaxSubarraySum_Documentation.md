# Maximum Subarray Sum (Kadane's Algorithm) Documentation

## Overview
This document describes the implementation and usage of the `maxSubarraySum` function in `Evaluation.java`, which finds the maximum sum of a contiguous subarray using Kadane’s algorithm.

## Function Signature
```
public static int maxSubarraySum(int[] nums)
```
- **Input:**
  - `nums` (int[]): The input array of integers.
- **Output:**
  - `int`: The maximum sum of any contiguous subarray.
- **Throws:**
  - `IllegalArgumentException` if the input array is null or empty.

## Algorithm
- Initializes two variables: `maxSoFar` and `maxEndingHere` to the first element.
- Iterates through the array, updating `maxEndingHere` as the maximum of the current element or the sum of `maxEndingHere` and the current element.
- Updates `maxSoFar` if `maxEndingHere` is greater.
- Returns `maxSoFar` as the result.

## Example Usage
```
int[] arr = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
int maxSum = Evaluation.maxSubarraySum(arr);
// maxSum is 6 (subarray [4, -1, 2, 1])
```

## Complexity
- **Time Complexity:** O(n), where n is the length of the array.
- **Space Complexity:** O(1), uses constant extra space.

## Edge Cases
- All negative numbers: Returns the largest (least negative) number.
- All positive numbers: Returns the sum of the entire array.
- Single element: Returns that element.
- Empty or null array: Throws `IllegalArgumentException`.
