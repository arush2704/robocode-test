# Strongly Connected Components (SCC) Documentation

## Overview
This document describes the implementation and usage of the `findStronglyConnectedComponents` function in `Evaluation.java`, which finds all strongly connected components (SCCs) in a directed graph using Kosaraju's algorithm.

## Function Signature
```
public static List<List<Integer>> findStronglyConnectedComponents(List<List<Integer>> graph)
```
- **Input:**
  - `graph` (List<List<Integer>>): Adjacency list of the directed graph. `graph.get(i)` contains the neighbors of node `i`.
- **Output:**
  - `List<List<Integer>>`: List of SCCs, each SCC is a list of node indices.
- **Throws:**
  - `IllegalArgumentException` if the graph is null.

## Algorithm
- Uses Kosaraju's algorithm:
  1. Perform DFS to fill nodes in a stack by finish time.
  2. Transpose the graph (reverse all edges).
  3. Pop nodes from the stack and perform DFS on the transposed graph to collect SCCs.
- Handles disconnected graphs and single-node SCCs.

## Example Usage
```
List<List<Integer>> graph = Arrays.asList(
    Arrays.asList(1),
    Arrays.asList(2),
    Arrays.asList(0)
);
List<List<Integer>> sccs = Evaluation.findStronglyConnectedComponents(graph); // [[0,1,2]]
```

## Complexity
- **Time Complexity:** O(V + E), where V is the number of vertices and E is the number of edges.
- **Space Complexity:** O(V + E) for visited arrays, stack, and result list.

## Edge Cases
- Disconnected graphs: Each component is handled.
- No edges: Each node is its own SCC.
- Null graph: Throws `IllegalArgumentException`.
