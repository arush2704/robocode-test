# Flatten Nested List Documentation

## Overview
This document describes the implementation and usage of the `flattenNestedList` function in `Evaluation.java`, which flattens an arbitrarily nested list of integers into a single flat list.

## Function Signature
```
public static List<Integer> flattenNestedList(List<?> nestedList)
```
- **Input:**
  - `nestedList` (List<?>): The nested list to flatten. Elements may be integers or other lists (arbitrarily nested).
- **Output:**
  - `List<Integer>`: The flattened list of integers.
- **Throws:**
  - `IllegalArgumentException` if the input is null or contains non-integer, non-list elements.

## Algorithm
- Uses recursion to traverse the nested list structure.
- For each element:
  - If it is an integer, add it to the result list.
  - If it is a list, recursively flatten it.
  - Otherwise, throw an exception.

## Example Usage
```
List<?> input = Arrays.asList(1, Arrays.asList(2, Arrays.asList(3, 4)), 5);
List<Integer> result = Evaluation.flattenNestedList(input);
// result is [1, 2, 3, 4, 5]
```

## Complexity
- **Time Complexity:** O(N), where N is the total number of integers in the nested structure.
- **Space Complexity:** O(N) for the result list, plus recursion stack depth proportional to nesting.

## Edge Cases
- Empty list: Returns an empty list.
- Null input: Throws `IllegalArgumentException`.
- List with invalid element: Throws `IllegalArgumentException`.
- Handles deeply nested and empty sublists correctly.
